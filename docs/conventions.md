# Conventions de l'équipe

À remplir après la réunion de cadrage :

- Statuts de candidature : déposée, en cours d'évaluation, acceptée, refusée
- Format des erreurs SOAP (SOAP Fault) et REST (JSON + code HTTP)
- Noms des opérations SOAP et des routes REST
- Règles de sécurité (authentification, HTTPS)
